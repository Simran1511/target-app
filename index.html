TARGET

A personal Windows app for logging daily progress on a study roadmap.

TARGET shows what a long-term roadmap schedules for each day and where to learn it, and it records what was actually done. Each week it compares the hours logged with the plan.

Everything is stored on the user's own computer. An optional sync feature keeps the same progress on several computers by saving it in a folder in the Google Drive account the user chooses. TARGET can only see the files it created there.

TARGET is a personal project. It is not a commercial product or a hosted service, and there is no account to create.
